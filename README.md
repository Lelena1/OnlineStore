# OnlineStore

Локальный интернет-магазин на Java: Spring Boot + Thymeleaf + SQLite. Запускается полностью локально — свой веб-сервер и своя файловая база данных, без внешних сервисов в рантайме (картинки товаров — единственное, что подгружается извне, по ссылкам).

## Возможности

- **Вход по имени** — без пароля. При вводе имени покупатель создаётся автоматически (если ещё не существует) и попадает в свой личный кабинет.
- **Каталог из 100 товаров** — 19 категорий, пагинация по 20 товаров на страницу.
- **Корзина** — добавление, изменение количества, удаление, автоматический пересчёт суммы. Корзина хранится в базе данных, а не в сессии — переживает перезапуск сервера.
- **Оформление заказа** — списывает товар со склада, сохраняет заказ и очищает корзину.
- **История заказов** и страница подтверждения заказа.

## Технологии

| Слой | Технология |
|---|---|
| Язык / сборка | Java 17, Maven |
| Веб | Spring Boot, Spring MVC, Thymeleaf (серверный рендеринг) |
| Данные | Spring Data JPA + Hibernate, SQLite (`org.xerial:sqlite-jdbc`, `hibernate-community-dialects`) |
| Стили | обычный CSS, без сборки и CDN |

## Структура проекта

```
com.example.shop
├── entity        — Customer, Product, CartItem, Order, OrderItem
├── repository    — Spring Data JPA репозитории
├── service       — бизнес-логика (вход, каталог, корзина, заказы)
├── controller    — маршруты (вход, каталог, корзина, заказы)
├── config        — конфигурация Spring MVC
├── web           — интерсептор проверки входа
└── seed          — загрузка каталога товаров при первом запуске
```

Товары для каталога хранятся в [`src/main/resources/data/products.json`](src/main/resources/data/products.json) — 100 позиций по 19 категориям с картинками (ссылки на Wikimedia Commons). При первом запуске `ProductSeeder` читает этот файл и наполняет базу данных.

## Как запустить

Нужен JDK 17+ и Maven.

```bash
mvn spring-boot:run
```

Приложение поднимется на `http://localhost:8080`. При первом запуске автоматически создастся файл базы данных `data/shop.db` и загрузится каталог из 100 товаров.

## База данных

SQLite-файл `data/shop.db` создаётся автоматически и не хранится в репозитории (см. `.gitignore`). Чтобы начать с чистой базой — удалите `data/shop.db*` и перезапустите приложение.

## Проверка работы

1. Открыть `http://localhost:8080/`, войти под любым именем.
2. Убедиться, что каталог показывает 100 товаров с картинками и пагинацией.
3. Добавить товары в корзину, изменить количество, удалить один — проверить пересчёт суммы.
4. Оформить заказ — проверить, что заказ появился в истории, а остаток товара уменьшился.
